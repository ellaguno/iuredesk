# Capturas para Iurefficient Apps

El lanzador [Iurefficient Apps](https://github.com/ellaguno/iureapps) muestra estas imágenes en
la ficha de la app. Las lee de esta carpeta en la rama `main`.

- `1.png`, `2.png`… hasta `6.png`: numeradas en orden y sin saltos (si falta `2.png`, ya no se
  lee `3.png`). Sólo PNG, de 8 MB y 4096 px por lado como mucho.
- `captions.txt`: un pie de foto por línea, en el mismo orden. Una línea vacía deja esa captura
  sin pie.

Los cambios se ven en el lanzador la próxima vez que se abre la ficha (o al pulsar *Comprobar*).

Son copias de `docs/screens/` (`1.png` ← `mail-light.png`, `2.png` ← `today-light.png`, `3.png` ← `calendar-light.png`, `4.png` ← `contacts-light.png`, `5.png` ← `notes-light.png`, `6.png` ← `mail-dark-dense.png`). Si cambias esas, actualiza también éstas.
