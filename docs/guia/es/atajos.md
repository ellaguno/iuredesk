# Atajos de teclado

Generado a partir de los comandos de IureDesk; no se edita a mano. El esquema se elige en Ajustes → General → Atajos de teclado. En macOS, Ctrl es ⌘. Todos los comandos están también en la paleta (Ctrl+K), que muestra su atajo.


## Correo

| Comando | Outlook | Gmail | Apple Mail |
|---|---|---|---|
| Nuevo mensaje | `Ctrl+N` | `C` | `Ctrl+N` |
| Responder | `Ctrl+R` | `R` | `Ctrl+R` |
| Responder a todos | `Ctrl+Shift+R` | `A` | `Ctrl+Shift+R` |
| Reenviar | `Ctrl+F` | `F` | `Ctrl+Shift+F` |
| Archivar | `Retroceso` | `E` | `Ctrl+A` |
| Eliminar | `Supr` | `#` | `Retroceso` |
| Marcar como leído / no leído | `Ctrl+Q` | `Shift+U` | `Ctrl+Shift+U` |
| Marcar / quitar seguimiento | `Insert` | `S` | `Ctrl+Shift+L` |
| Mover a carpeta… | `Ctrl+Shift+V` | `V` |  |
| Buscar en el correo | `Ctrl+E` | `/` | `Ctrl+Alt+F` |
| Abrir en ventana | `Shift+Enter` | `Shift+Enter` | `Shift+Enter` |
